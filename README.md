# Sale_tax_calculator
Aplicación móvil que calcula impuestos de compra en Colombia por categoría de producto. Con 8 botones (canasta básica, alimentos con IVA 5%, bienes generales, restaurantes, licores, suntuarios, bolsas plásticas, cigarrillos/vapeadores), el usuario ingresa un valor o cantidad y obtiene al instante el impuesto según las tarifas vigentes de IVA e INC.
